# 智瞰危局 — 项目架构文档

> **项目名称**：灾害/突发事件：谣言与求助信息融合识别与资源调度系统  
> **版本**：v2.0  
> **更新日期**：2026年3月  

---

## 1 系统总览

本系统「**智瞰危局**」是一个面向自然灾害与突发事件的**人机协同应急情报中台**，核心能力为：

```
多源信息接入 → 文本清洗 → AI大模型研判 → 向量化去重聚类 → 人工审核 → 地图态势展示 → 智能派单调度 → 过程留痕
```

系统采用**前后端分离 + AI微服务**三层架构，技术栈如下：

| 层级 | 技术 | 端口 | 职责 |
|------|------|------|------|
| **前端** | Vue 3 + Vite + Element Plus + Three.js + ECharts | 3000 | 态势展示、交互操作、3D可视化 |
| **后端** | Spring Boot 2.7.3 + MyBatis Plus + MySQL + WebSocket | 8080 | 业务逻辑、数据持久化、实时推送 |
| **AI 服务** | Python Flask + 通义千问(qwen-plus) + text-embedding-v2 | 5001 | 灾种研判、谣言检测、文本向量化 |

### 3.4 WebSocket 实时推送

**端点**：`ws://localhost:8080/ws/message?token=<JWT>`

| 消息类型 | 方向 | 说明 |
|----------|------|------|
| `PING / PONG` | 双向 | 心跳(30秒) |
| `NEW_MESSAGE` | 服→客 | 新原始消息到达 |
| `NEW_INCIDENT` | 服→客 | 新聚合事件生成 |
| `INCIDENT_UPDATE` | 服→客 | 事件状态变更 |
| `RESPONDER_UPDATE` | 服→客 | 人员状态变更 |
| `TASK_UPDATE` | 服→客 | 派单任务状态变更 |
| `SYSTEM_NOTICE` | 服→客 | 系统通知 |
| `ALERT` | 服→客 | 高危告警 |
| `DATA_RESET` | 服→客 | 数据重置通知，前端清空本地状态 |
| `AGGREGATION_VISUAL` | 服→客 | 聚合可视化数据 |

### 3.5 认证与鉴权

- **算法**：HMAC-SHA256 (JJWT)
- **Admin 秘钥**：`hrd`，有效期 7200 秒
- **Responder 秘钥**：`responder`，有效期 7200 秒
- **拦截器**：`JwtTokenAdminInterceptor` / `JwtTokenResponderInterceptor`
- **排除路径**：`/admin/login`、`/responder/login`、WebSocket、Swagger
- **双角色同时登录**：前端使用角色前缀隔离 Token 存储（`admin_access_token` / `responder_access_token`），管理员和执勤人员可在同一浏览器同时登录不互相干扰，Axios 请求同时携带双角色 Token

### 4.2 核心表定义

| 表名 | 核心字段 | 说明 |
|------|----------|------|
| **users** | id, username, password, role | 系统账户(角色1=管理员, 2=执勤人员) |

### 4.3 状态机定义

**事件状态 (incidents.status)**：

```
0:待审核 ──▶ 1:已确认 ──▶ 2:已派单 ──▶ 3:处理中 ──▶ 4:已完成
    │                                                      
    └──▶ 5:已驳回
```

**执勤人员状态 (responders.status)**：

```
0:离线 ◀──▶ 1:空闲 ──▶ 2:已派单 ──▶ 3:执行中 ──▶ 1:空闲
```

**派单任务状态 (dispatch_tasks.status)**：

```
0:待接受 ──▶ 1:已接受 ──▶ 3:已出发 ──▶ 4:已到达 ──▶ 5:处理中 ──▶ 6:已完成
    │
    └──▶ 2:已拒绝
    
任何状态 ──▶ 7:需增援
```

## 6 AI 微服务架构

### 6.1 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 运行框架 | Flask | 轻量级Python Web框架 |

| 文本向量化 | text-embedding-v2 | 阿里百炼平台，1024维向量 |

### 6.2 API 端点

| 端点 | 方法 | 输入 | 输出 | 功能 |
|------|------|------|------|------|
| `/api/analyze` | POST | `{text}` | `{disaster_type, info_type, severity, confidence, suggestion, keywords, is_rumor}` | 综合研判 |
| `/api/rumor` | POST | `{text}` | `{is_rumor, confidence, reason, suggestion}` | 谣言检测 |
| `/api/embedding` | POST | `{text}` | `{embedding[], dimension}` | 文本向量化 |
| `/api/embedding/batch` | POST | `{texts[]}` | `{embeddings[], dimension}` | 批量向量化 |
| `/api/similarity` | POST | `{vec1, vec2}` 或 `{text1, text2}` | `{similarity}` | 相似度计算 |
| `/health` | GET | — | `{status, model}` | 健康检查 |

## 7 数据流架构

### 7.1 消息处理全链路

```
  ┌──────────────┐
  │ 模拟数据源    │  (微博/论坛/群聊 模拟器)
  └──────┬───────┘
         ▼
  ┌──────────────┐
  │ 消息入库      │  MessageController → MessageService → messages表
  └──────┬───────┘
         ▼
  ┌──────────────┐
  │ AI 研判      │  ClusteringService → ModelService → Python(qwen-plus)
  │  • 灾种识别  │  返回：灾种、信息类型、严重度、置信度、是否谣言
  │  • 谣言检测  │
  │  • 置信度    │
  └──────┬───────┘
         ▼
  ┌──────────────┐
  │ 向量化聚类    │  ModelService → Python(text-embedding-v2)
  │  • 文本嵌入  │  与所有现有事件计算余弦相似度
  │  • 相似度≥阈值│  → 合并到已有事件 (incident_evidences)
  │  • 相似度<阈值│  → 创建新事件 (incidents)
  └──────┬───────┘
         ▼
  ┌──────────────┐
  │ WebSocket推送 │  WebSocketServer → 前端实时刷新
  │  NEW_MESSAGE  │
  │  NEW_INCIDENT │
  └──────────────┘
```

### 7.2 派单调度链路

```
  管理员确认事件
       ▼
  智能匹配: 灾种→岗位→空闲人员→距离最近
       ▼
  创建 dispatch_task (status=0 待接受)
       ▼
  WebSocket → 执勤人员收到通知
       ▼
  ┌────────┐     ┌────────┐
  │ 接受   │     │ 拒绝   │
  └───┬────┘     └───┬────┘
      ▼              ▼
  出发→到达→处理   记录原因
  →完成→反馈       可重新派单
      ▼
  事件 status → 4:已完成
```

## 9 安全设计

| 安全措施 | 实现方式 |
|----------|----------|
| **认证** | JWT Token，请求头 `Authorization: Bearer <token>` |
| **权限隔离** | Admin 和 Responder 双角色独立拦截器 |
| **密码存储** | MD5 哈希（生产环境建议升级为 bcrypt） |
| **SQL注入防护** | MyBatis Plus 参数化查询 |
| **XSS防护** | Vue 自动转义 + Element Plus 组件；`dangerouslyUseHTMLString` 场景统一使用 `esc()` HTML实体转义函数 |
| **CORS** | 后端配置允许开发端口跨域 |
| **WebSocket认证** | URL Token 参数 + JWT 校验 |
| **敏感信息** | 发布者信息脱敏展示 |
