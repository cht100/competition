# 灾害/突发事件：谣言与求助信息融合识别与资源调度系统

## —— 计算机设计大赛参赛作品介绍文档

---

### 一、作品概述

本作品「**智瞰危局**」是一个面向自然灾害与突发事件场景的**人机协同应急情报中台**，旨在解决应急管理中 "海量多源信息难以快速甄别、谣言与真实求助混杂、应急资源调度缺乏智能决策支持" 三大痛点。

系统以**大语言模型（LLM）**为核心驱动力，实现了从**多源信息接入→智能研判→去重聚类→人工审核→态势展示→资源调度→过程留痕**的完整业务闭环，具备实际应急管理场景的落地潜力。

**核心价值主张**：

> "让AI成为应急指挥员的智能参谋，使每一条求助信息都不被淹没，每一条谣言都无处遁形。"

---

### 二、解决的核心问题

| 现实痛点 | 本系统解决方案 |
|----------|----------------|
| 灾害发生时社交媒体信息爆炸，人工难以逐条甄别 | 大模型自动研判灾种、严重度、可信度，AI预过滤后人工复核 |
| 谣言与真实求助混杂，易误导决策 | 多维度谣言检测 + 置信度评分，疑似谣言自动标记隔离 |
| 同一事件多方重复上报，信息碎片化 | NLP向量化语义聚类，自动将同一事件的多条消息合并为"事件卡片" |
| 应急资源调配缺乏智能辅助 | 根据灾种自动匹配岗位，智能推荐最优执勤人员 |
| 应急过程缺少记录追溯 | 全链路留痕——从原始消息、AI研判、人工审核到派单反馈 |

### 四、核心功能与创新点

#### 4.1 大模型驱动的智能研判（核心创新）

本系统将**通义千问大语言模型**深度集成至应急信息处理的全流程中：

- **灾种自动识别**：10类灾种精准分类（洪涝/地震/火灾/台风/泥石流/滑坡/干旱/暴雪/雷电/其他）
- **信息类型判定**：自动区分求助、报平安、灾情通报、物资需求、人员失踪、道路阻断等7种类型
- **4级严重度评估**：轻微→一般→严重→特别严重
- **5档置信度评分**：极高(90+)→高(70-89)→中(50-69)→低(30-49)→极低(<30)
- **处置建议生成**：模型输出可读的应急建议与关键词提取
- **可解释性**：AI决策过程透明可审计，支持展开查看"推理依据"

**创新点**：区别于传统规则引擎，本系统利用LLM的语义理解能力实现"软判断"，能应对措辞多变、表述模糊的社交媒体文本。

#### 4.2 NLP向量化语义聚类（核心创新）

利用 **text-embedding-v2** 模型实现真正的语义级消息去重与事件聚合：

```
新消息 → 1024维向量化 → 与所有已有事件向量计算余弦相似度
  ├── 相似度 ≥ 0.75 → 合并至已有事件（追加为证据链）
  └── 相似度 < 0.75 → 创建新聚合事件
```

- 多条消息自动合并为一个"事件卡片"
- 保留完整证据链（每条原始消息可追溯）
- 综合置信度随多源佐证动态提升（多源一致性越高越可信）
- 相似度阈值可实时调整

**创新点**：基于深度学习向量的语义聚类远优于传统关键词匹配，能正确合并"措辞不同但描述同一事件"的消息。

#### 4.3 多维谣言检测与可视化（核心创新）

在AI研判的基础上增设独立的谣言检测管道，并提供多层次可视化展示：

- **信息来源可靠性评估**：分析发布者特征
- **内容事实性验证**：逻辑自洽性检查
- **谣言模式特征匹配**：常见谣言句式识别
- **处理建议输出**：等待权威确认 / 发布辟谣 / 降低传播风险
- **状态标记**：疑似谣言消息红色高亮，驳回时记录谣言判定
- **⭐ 事件详情谣言雷达图**：ECharts 5维雷达图可视化（来源可靠性/内容一致性/逻辑合理性/细节完整度/情绪客观性）
- **⭐ 谣言判定标签**：✅信息可信 / ⚠️待核实 / ❌谣言 三级彩色标识
- **⭐ 事件流谣言横幅**：红色闪烁警告横幅 + 绿色可信横幅，脉冲动画强化视觉冲击
- **⭐ 统计看板谣言仪表盘**：Gauge 图表实时展示谣言占比，绿→青→黄→红四色分层

#### 4.4 全链路智能调度闭环

```
事件确认 → 智能匹配(灾种→岗位→空闲人员) → 派单 → 接受/拒绝
    → 出发 → 到达 → 处理 → 完成反馈 → 事件关闭
```

- **智能岗位匹配**：火灾→消防、医疗事件→医疗人员、治安事件→警务人员
- **状态实时回传**：WebSocket推送每一步状态变更
- **双向沟通**：执勤人员可拒绝并说明原因，管理员可重新派单
- **过程留痕**：全部操作记录审计日志

#### 4.5 科幻风格 3D 态势地图

基于 **Three.js** 打造的赛博朋克风格城市3D场景：

- 🏙️ **赛博朋克建筑群**：线框描边 + 自发光 + 混色窗户 + 屋顶信标
- 📡 **雷达扫描效果**：大范围高亮度旋转扇形扫描光，前沿扫描亮线 + 中心发光环，视觉冲击力强
- 🔦 **事件光柱标记**：50米高光柱 + 3层冲击波扩散环 + 核心球体发光
- 🌟 **中心全息投影**：双层光束柱 + 三环脉冲环 + 呼吸光球 + 底座发光环，科幻感十足
- 🎥 **电影级摄像机**：入场俯冲动画、飞行镜头（fly-to）、自动旋转
- 🌫️ **景深雾气**：指数雾效 + ACES色调映射
- 💡 **实时动画**：全场景呼吸灯效、环形脉冲、雷达扫描

#### 4.6 实时通信架构

- **WebSocket 长连接**：8种消息类型实时推送
- **自动重连与心跳**：3秒重连间隔、30秒心跳
- **零延迟体验**：新消息/事件/状态变更毫秒级推送

#### 4.7 双角色系统

- **管理员/指挥员**：全局态势监控、事件审核、智能派单、统计分析
- **执勤人员**：任务接收、进度反馈、在线状态管理、个人3D态势地图
- 完整的权限隔离，JWT 双秘钥认证
- **双角色同时登录**：管理员与执勤人员可在同一浏览器同时在线，角色前缀 Token 存储互不干扰

### 十、运行方式

```bash
# 环境依赖：Java 17+, Node.js 16+, Python 3.8+, MySQL 8.0+

# 1. 初始化数据库
mysql -u root -p -e "CREATE DATABASE gproject DEFAULT CHARSET utf8mb4"
mysql -u root -p gproject < gproject-master/server/src/main/resources/db/schema.sql

# 2. 启动后端服务 (端口8080)
cd gproject-master && mvn spring-boot:run -pl server

# 3. 启动AI服务 (端口5001)
cd model_service && pip install flask dashscope numpy && python app.py

# 4. 启动前端 (端口3000)
cd platform && npm install && npm run dev

# 5. 访问系统
# 管理员端：http://localhost:3000    账号 admin / 123456
# 执勤人员端：http://localhost:3000/responder/login   账号 zhangwei / 123456
```
